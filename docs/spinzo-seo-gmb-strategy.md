6. **Local competitors have JustDial/Sulekha presence** but zero website SEO. Spinzo can dominate with proper location pages

### 3.3 Structured Data Enhancement

Current: `DryCleaningOrLaundry` + `LocalBusiness` on home and location pages.

**Add these schemas**:
1. **Service schema** on home page — one per service type:
   ```json
   {
     "@context": "https://schema.org",
     "@type": "Service",
     "name": "Wash & Fold - Spinzo",
     "provider": { "@type": "LocalBusiness", "name": "Spinzo" },
     "areaServed": ["BTM Layout", "Koramangala", ...],
     "serviceType": "Wash & Fold",
     "offers": {
       "@type": "Offer",
       "price": "85",
       "priceCurrency": "INR",
       "priceSpecification": { "@type": "UnitPriceSpecification", "unitText": "kg" }
     }
   }
   ```
2. **AggregateRating** with actual rating count on each location page
3. **Service** + **AreaServed** relationship in JSON-LD
4. **ShippingDeliveryTime** — for the 30min pickup / 6hr delivery USP
